# Перемена

Браузерная игра для компьютера, Android и iOS: исследуй объёмную школу, собери 20 тетрадей и вернись к выходу, пока персонаж по семейным фотографиям играет с тобой в догонялки.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Открой адрес, напечатанный Vite. Для сборки: `npm run build`, для просмотра сборки: `npm run preview`. Проверки игровой логики: `npm test`.

## Управление

- WASD — движение, мышь — обзор.
- Shift — бег, E — открыть или закрыть дверь / взять тетрадь / выйти из школы.
- M — карта, Esc — пауза.
- Если браузер не разрешает захват указателя, удерживай левую кнопку мыши для обзора. Стрелки влево/вправо также поворачивают камеру; вверх/вниз двигают вперёд/назад.

Школа занимает сетку 32 × 32: 16 классов с 32 открывающимися дверями. В классах спрятаны 20 тетрадей; на карте показаны двери и выход, без подсказок с местами тетрадей. Преследователь умеет открывать закрытые двери с задержкой 0,85 секунды.

Есть два темпа погони, 12 секунд форы от первого соперника, восстановление энергии, локальный рекорд, выключение звука и полный экран. Раунд приостанавливается при переключении окна или вкладки.

## Реализация и материалы

Three.js + Vite, без фреймворка интерфейса. Школа построена из объёмной геометрии, сгруппированной через InstancedMesh; персонаж — поворачивающаяся к игроку плоскость с 8 кадрами бега и отдельной позой стоя. Поза стоя используется в меню, во время форы, остановок у дверей и паузы; бег включается только при фактическом перемещении. Shader убирает зелёный фон исходного листа непосредственно при отрисовке. Звук синтезируется локально через Web Audio.

`public/assets/runner-sheet.png` — кадры бега, `public/assets/runner-idle.png` — поза стоя, сгенерированные ImageGen по предоставленным фотографиям. `concepts/style-comparison.png` — исходное сравнение стилей. Оригиналы фотографий не входят в приложение. Изображения персонажа сохраняют внешность ребёнка; игра опубликована на GitHub Pages.

Это первый игровой прототип. Персонаж использует фронтальные спрайты, а не скелетную 3D-модель; в анимации возможны небольшие различия между сгенерированными кадрами. Декоративная мебель не имеет физических коллайдеров; стены и закрытые двери ограничивают передвижение игрока и преследователя. Поддерживаются компьютеры и телефоны с WebGL2. На сенсорных устройствах снижены разрешение рендера и размер теней.


## Телефон и установка

Игра: https://izotovdenis.github.io/escape/

- Слева — аналоговый джойстик. Небольшое отклонение позволяет идти медленнее.
- Проведи пальцем по свободной части сцены справа, чтобы осмотреться. Движение и обзор работают одновременно.
- Удерживай «Бег» для ускорения: отпустил — снова идёшь. Бег работает одновременно с джойстиком и обзором. «Открыть», «Закрыть», «Взять» и «Выход» появляются на кнопке по ситуации.
- Карта и пауза находятся вверху справа. При сворачивании игра приостанавливается, касания сбрасываются.
- Игра рассчитана на горизонтальный экран, учитываются безопасные зоны. При старте запрашиваются полный экран и альбомная ориентация; если браузер не поддерживает поворот, появляется подсказка повернуть телефон. В портретной ориентации игровой таймер и погоня останавливаются до поворота.

Android: открой ссылку в Chrome, затем меню ⋮ → «Установить приложение» / «Добавить на главный экран». Когда браузер разрешает установку, в раскрывающейся подсказке игры появляется кнопка «Установить игру».

iPhone / iPad: открой ссылку в Safari → «Поделиться» → «На экран Домой». Если доступен переключатель «Открывать как веб-приложение», оставь его включённым.

После сообщения «Сохранено на устройстве» игра запускается без интернета, пока браузер хранит её данные. Очистка данных браузера удаляет офлайн-копию и рекорд. Это веб-приложение, установка из App Store или Google Play не нужна.

Сборка создаёт `sw.js` с версией по содержимому всех файлов; кешируются сцена, код, стили и значки. Новая версия не прерывает текущий раунд: закрой все окна игры и открой снова или нажми «Обновить игру» в подсказке главного меню. Service worker отключён в режиме разработки.

Значок приложения создан через ImageGen. Проверки перед публикацией: `npm test`, `npm run build`; мобильные касания проверены в эмуляции браузера. Реальная установка на iOS/Android проверяется на устройстве.

Второй соперник в красной толстовке гуляет с начала раунда. Видит на 22 метра в секторе 120° перед собой; стены и закрытые двери закрывают обзор. Потеряв игрока, возвращается к прогулке по коридорам, выбирает пути на развилках и изредка разворачивается (через 14–30 секунд). Для него есть отдельные восемь кадров спереди и со спины. На мобильном включено сглаживание и повышен предел плотности рендеринга до 1.5.


## Котики и собака

Два котика по фотографиям гуляют по коридорам школы и останавливаются рядом с игроком. Их отметки на карте следуют за ними. Подойди и нажми E (на телефоне — «Погладить»): Рыжик полностью восстанавливает энергию, Полосатик отмечает ближайшую несобранную тетрадь на карте на 20 секунд. Каждый помогает раз в 25 секунд. Золотистый спаниель тоже гуляет, периодически приседает и оставляет кучку на текущем месте. Все кучки сохраняются до конца раунда, даже если на них наступить; наступив на неё, игрок двигается вдвое медленнее 2,5 секунды. Пауза останавливает таймеры, новый раунд сбрасывает эффекты. Спрайты созданы через ImageGen и хранятся в `public/assets/pets-sheet.png`.


Звуки: шаги по плитке, скрип и хлопок дверей, щелчок замка, шорох тетрадей, мяуканье и мурчание, лай и собачьи сюрпризы. Близкие соперники слышны по шагам; громкость и стереопозиция зависят от расстояния и направления. Эффекты синтезируются локально, работают офлайн. Кнопка ♫ включает и выключает весь звук, пауза останавливает эффекты. После прерывания звука телефоном следующее касание повторно активирует аудио.

## Аквапарк — отдельная игра

Открой `/escape/aquapark.html` или нажми «Новая игра: Аквапарк» в меню «Перемены». Школьная игра сохранена на прежнем адресе; из аквапарка есть обратная ссылка.

Бесконечный раннер с тремя дорожками и двумя выбираемыми персонажами из школьной игры. Стрелки влево/вправо или A/D меняют дорожку, вверх/W/пробел — прыжок, вниз/S — подкат, Esc — пауза. На телефоне работают свайпы по сцене и четыре кнопки. Круги нужно перепрыгивать, под арками — скользить, фламинго — перепрыгивать или обходить. Мороженое добавляет очки; жёлтый защитный круг спасает от одного столкновения. Скорость постепенно растёт, в каждом ряду остаётся свободная дорожка. Выбранный персонаж и рекорд дистанции сохраняются на устройстве. Переключение вкладки ставит забег на паузу.

Аквапарк включён в общую сборку и офлайн-кеш существующего приложения. Для первого сохранения офлайн открой «Перемену» и дождись сообщения о сохранении. Новая игра использует отдельные `src/aqua.js`, `src/aqua-logic.js`, `src/aqua.css`; тесты обоих режимов запускаются через `npm test`.

Скольжение в аквапарке: ↓ / S или свайп вниз запускает отдельную четырёхкадровую анимацию на животе с руками вперёд и брызгами. `public/assets/slide-sheet.png` содержит первый скин в верхнем ряду, второй — в нижнем. Во время скольжения изображение защитного круга скрыто, его защита сохраняется и показана в HUD.

Темп аквапарка повышен: стартовая скорость 22 вместо 12, максимальная — 38 вместо 24; набор скорости и смена дорожек ускорены. Интервал рядов препятствий учитывает скорость, оставляя минимум 0,95 секунды между рядами. Добавлены плавные автоматические изгибы трассы в обе стороны и расширение обзора при разгоне. Концепты нового окружения для выбора находятся в `concepts/aquapark-directions.png`; это изображения направления дизайна, не текущая игровая графика.

## Солнечное оформление аквапарка

В аквапарке используется отдельное окружение `src/aqua-sunny.js`: объёмная плиточная трасса с плавными изгибами, ограждения, секционные оранжевые горки, анимированная вода, мягкая тень героя и силуэтные тени пальм. Декорации переиспользуются в 12 циклических секциях.

Новые материалы созданы ImageGen и подключены непосредственно к игре:
- `sunny-panorama.png` — дальняя панорама тропического парка;
- `sunny-props.png` — атлас из восьми декораций: пальмы, павильоны, растения, водопад, утка и пляжная мебель;
- `sunny-tiles.png` — фактура каменной дорожки;
- `sunny-runners.png` — оба мальчика в мультяшном стиле, по четыре кадра спереди и со спины;
- `sunny-slide.png` — четыре кадра скольжения на животе для каждого мальчика.

Окружение сочетает 3D-геометрию и плоские художественные спрайты. В меню используются портреты ImageGen; в забеге восстановлены детализированные спрайты ImageGen, соответствующие этим портретам. Файлы и визуальный стиль «Перемены» сохранены. Проверены сборка, 23 теста и забег в браузере; производительность на реальном телефоне отдельно не измерялась.

## Герои и короткие повороты

`src/aqua-runner.js` отображает качественные ImageGen-спрайты обоих мальчиков с кадрами спереди, со спины и отдельной анимацией скольжения. Экспериментальные геометрические модели заменены обратно на нарисованные фигурки по пожеланию пользователя. Сохраняются мягкий наклон при смене дорожки, контактная тень и остановка анимации на паузе. `src/aqua-obstacles.js` содержит округлые полосатые круги, надувные арки и фламинго с бликами и контактными тенями. Повороты занимают около 123 метров, за ними около 67 метров прямой трассы. Плитка движется в направлении препятствий, с той же линейной скоростью.

### Обновление темпа и графики аквапарка

- Стартовая скорость 16, плавный разгон по дистанции до 34.
- Фиксированная форма маршрута: участки поворота приходят издали, максимальная кривизна уменьшена.
- Бег чередует исходные и отражённые фазы шага с небольшим движением корпуса.
- Новый ImageGen-атлас `sunny-obstacles.png`: круг, арка, фламинго и мороженое с прозрачностью; коллекционные предметы плавно покачиваются.

Персонажи перерисованы в более округлом мультяшном стиле с объёмным светом: `sunny-runners-volume.png` и `sunny-slide-volume.png`. Исходные рисунки сохранены.

### Текущие персонажи

Восстановлены нарисованные персонажи ImageGen. При скольжении спрайт слегка приподнят и наклонён к камере, чтобы не выглядеть расплющенным. Экспериментальные программные 3D-фигурки отключены.

Бег использует сглаженное смешивание соседних поз с корректной прозрачностью на каждом кадре отрисовки. Исходные рисунки и чередование ног сохранены; вертикальное покачивание синхронизировано с полным шагом.

Главное меню аквапарка оформлено отдельной иллюстрацией ImageGen `sunny-menu.png`, адаптивными карточками героев и кнопкой старта. На узких экранах меню прокручивается, если высоты недостаточно.

Главный адрес `/escape/` открывает аквапарк. Школьная игра сохранена по `/escape/school.html` и доступна через кнопку «Перемена». HTML-страницы обновляются из сети с офлайн-резервом.

## Севен-переполох

Главная страница `/escape/` (`index.html`) теперь открывает «Севен-переполох»;
прямой адрес — `/escape/seven.html`. Прежний `/escape/fruit.html` сохранён
как дополнительный адрес этой же игры. Аквапарк доступен по кнопке вверху
и по `/escape/aquapark.html`, «Перемена» — `/escape/school.html`.

Мальчик Жёлтые носки собирает перекус в тайском мини-маркете в стиле 7-Eleven.
По четырём лентам едут пончики, горячие тостики и чили. Подставляй корзинку
до того, как еда достигнет конца ленты:

- Q / A — слева вверху / внизу; E / D — справа вверху / внизу.
- Стрелки меняют сторону и высоту корзинки; 7 / 1 / 9 / 3 на цифровом блоке тоже работают.
- На телефоне — четыре кнопки по краям или касание соответствующей части сцены.
- Esc, P, пробел или кнопка Ⅱ — пауза. Переключение окна или вкладки тоже ставит игру на паузу.

Розовый и шоколадный пончики дают по одному очку, тостик — два. Три пропуска
еды завершают раунд. Чили можно безопасно пропустить: жизнь и серия поимок
сохранятся. Пойманный перец не отнимает жизнь, но сбрасывает серию и на четыре
игровые секунды делает лицо красным. Повторный перец обновляет этот срок;
пауза замораживает эффект, новый раунд сбрасывает его. Первые пять предметов —
еда без чили, два перца подряд не появляются.

Темп плавно растёт с игровым временем: скорость движения и появления еды
увеличивается от ×1 к ×3,4. Каждые десять пойманных закусок повышают уровень.
Редкая бутылочка тайского Red Bull включает турбо на 15 игровых секунд:
еда движется вчетверо быстрее, а мальчик сам переключает позы, ловит еду
и избегает чили. Таймер и золотая подсветка показывают оставшееся время;
после турбо возвращаются ручное управление и текущий обычный темп раунда.
Пауза замораживает турбо. Пропуск бутылочки не отнимает жизнь и серию.
Она появляется не раньше 20-й секунды с вероятностью 3% среди допустимых
появлений, минимум через 45 секунд после предыдущей и только вне турбо.
Есть режимы «Час пик» (`classic`) и «Без спешки» (`relaxed`): во втором еда
движется и появляется медленнее.
Локальные рекорды сохраняются отдельно для каждого режима. Меню результатов
показывает очки, лучшую серию, рекорд и количество пойманных пончиков,
тостиков, перчиков и включений турбо.

Мягкий объёмный стиль аквапарка перенесён в магазин. Материалы ImageGen находятся
в `public/assets/seven-store-clean.png` (магазин без игровых полок),
`public/assets/seven-shelf.png` (отдельная полка на прозрачном фоне),
`public/assets/seven-food.png` (еда), `public/assets/seven-energy.png` (бутылочка
тайского энергетика), `public/assets/seven-boy-directions.png`
и `public/assets/seven-boy-variants.png` (по два рисунка для каждой из четырёх поз).
Файлы с суффиксом `-spicy.png` содержат соответствующие реакции на чили. Сцена, персонаж
и эффекты отрисовываются Canvas 2D; WebGL для этой игры не требуется.
Четыре игровые полки расставляются независимо от фона. Правая пара зеркально
отражает левую; движение еды использует те же координаты, что и полки.
Персонаж не зеркалится: правые позы нарисованы отдельно, эмблема остаётся на
одной ноге. Варианты чередуются при возвращении в позицию и после поимки еды;
при уменьшенном движении используется стабильный вариант. Корзина каждой позы
задаёт точку окончания падения, а размер тела и линия пола остаются стабильными.
Мальчик смещается к выбранной паре полок: положение корзины привязано к краю
полки, в том числе на широких экранах. Полки занимают примерно четверть ширины
с ограничением масштаба, чтобы на широком экране не становиться чрезмерно большими.
Фон один раз растягивается на весь игровой canvas без повторов по краям;
персонаж и еда сохраняют пропорции. Данные поз находятся в `src/seven-boy.js`.
Новые страницы и материалы включены в сборку и общий офлайн-кеш.
Логика остаётся в `src/fruit-logic.js`, интерфейс — в `src/fruit.js`,
отрисовка — в `src/fruit-scene.js`; проверки запускаются командой `npm test`.


## За перекусом — магазин 7-Eleven

Новая отдельная игра: `shop.html`. Локально: `http://127.0.0.1:5175/escape/shop.html` при запуске `npm run dev -- --port 5175`.

Небольшой магазин 10 × 12 м в выбранном направлении «Как в Таиланде»: чипсы, пекарная стойка с пончиками, охлаждаемые сэндвичи и напитки. Товары моделируются объёмной геометрией с локально создаваемыми текстурами. Концепты четырёх отделов, созданные ImageGen, доступны из меню: `public/assets/shop-departments.png`. Это визуальные референсы; игровая сцена использует упрощённые 3D-модели.

Задание содержит 2–4 категории и 1–3 товара каждой. Подойди к полке, наведи прицел и нажми E. Лишние товары не засчитываются, выбранные исчезают с полки. Заверши список у кассы справа от входа. Следующий заказ меняется, полки пополняются. Таймер учитывает только активную игру; проигрыша по времени нет.

Управление: WASD — идти; мышь или удержание кнопки мыши — смотреть; стрелки — движение вперёд/назад и поворот; Shift — ускориться; E — взять товар / завершить заказ; M — карта; Esc — пауза. На телефоне: левый джойстик, свайп по сцене, кнопка «Взять». При скрытии страницы или потере фокуса игра приостанавливается.

Проверки: `npm test`, `npm run build`. Browser smoke: сбор четырёх категорий через наведение и E, чек, следующий заказ, движение, карта и остановка таймера на паузе. Мобильные размеры 390 × 844 и 844 × 390 проверяются в Chromium с сенсорной эмуляцией; реальное устройство отдельно не проверялось. При наличии `?verify=1` только в dev-сборке доступен диагностический мост для постановки камеры в browser smoke; в production он удаляется сборщиком.


## Общий главный экран

Главная страница `/escape/` теперь открывает «Солнечные игры» с четырьмя ссылками: `school.html`, `aquapark.html`, `seven.html`, `shop.html`. `fruit.html` — совместимый прежний адрес «Севен-переполоха». В каждой игре есть возврат «Все игры». Общий экран адаптирован для портретного телефона; выбор игр не требует загрузки Three.js. Публикация использует существующий GitHub Pages workflow.
